------------------------------------------------------------------------
2. WHY (evidence)
------------------------------------------------------------------------
On attack.mitre.org (checked directly):
  - T1046 Network Service Discovery = "listing of services running on
    remote hosts ... using tools brought onto a system". This is the
    post-compromise / internal-discovery interpretation (Discovery).
  - T1595 Active Scanning = "probing victim infrastructure via network
    traffic" BEFORE access. T1595.001 Scanning IP Blocks is exactly a
    port scan against a target's address space (Reconnaissance / PRE).
    Its published detection guidance = "monitor network data for uncommon
    data flows", which is what our ML/flow pipeline does.

Data-verified from data/subset captures:
  - PortScan: 158,930 flows from 172.16.0.1 (attacker net) probing
    victim 192.168.10.x across many ports (80/21/22/443/444/139...).
    Pre-compromise, external, active scanning => Reconnaissance.
  - DDoS: 128,027 flows from 172.16.0.1 to 192.168.10.50:80 => a flood
    saturating the link/service => T1498 (bandwidth/network flood), NOT
    T1499 (endpoint resource exhaustion).

Decision: external port scan of the victim infrastructure = T1595.
