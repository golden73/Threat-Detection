HIGH INC-001 - 172.16.0.1: FTP-Patator (T1110.001)

Knowledge-base assistant report

INC-001 (HIGH)

Summary

Source 172.16.0.1 showed 1 detected activity burst(s) (7,923 flows) between 2017-07-04T09:19:00 and 2017-07-04T10:20:00, covering the tactics: Credential Access. Target(s): 192.168.10.50.

Timeline

  • 2017-07-04T09:19:00 to 2017-07-04T10:20:00: FTP-Patator (7,923 flows, 1 target ports, avg confidence 1.00)

ATT&CK mapping

  • T1110.001 Brute Force: Password Guessing (tactic: Credential Access): Many login attempts against a service (here FTP or SSH) to guess valid credentials. If one succeeds, the attacker gains access to the system.

Immediate actions

  • Block the source and check authentication logs for any SUCCESSFUL login from it.
  • If a login succeeded, treat the account as compromised: reset the password, end sessions, and review what the account did.

Longer-term fixes

  • Enforce strong passwords and account lockout / fail2ban.
  • Use SSH keys and multi-factor authentication; avoid plain FTP (use SFTP).
  • Do not expose SSH/FTP to the internet unless necessary; restrict by IP or VPN.

ATT&CK mitigations

  • M1036 Account Use Policies; M1032 Multi-factor Authentication; M1027 Password Policies; M1018 User Account Management

Caveats

  • Detections come from an ML model on network flow data; confirm with firewall, server and authentication logs before concluding compromise.
  • Source IPs may be NAT or shared addresses; attribution is not implied.

CRITICAL INC-003 - 172.16.0.1: PortScan (T1595) -> DDoS (T1498)

Knowledge-base assistant report

INC-003 (CRITICAL)

Summary

Source 172.16.0.1 showed 3 detected activity burst(s) (286,793 flows) between 2017-07-07T13:52:00 and 2017-07-07T16:16:00, covering the tactics: Reconnaissance -> Impact. Target(s): 192.168.10.50.

Multiple stages from one source suggest a deliberate, staged attack rather than a one-off event.

Timeline

  • 2017-07-07T13:52:00 to 2017-07-07T14:16:00: PortScan (363 flows, 5 target ports, avg confidence 1.00)
  • 2017-07-07T14:51:00 to 2017-07-07T15:23:00: PortScan (158,422 flows, 998 target ports, avg confidence 1.00)
  • 2017-07-07T15:56:00 to 2017-07-07T16:16:00: DDoS (128,008 flows, 1 target ports, avg confidence 1.00)

ATT&CK mapping

  • T1595 Active Scanning (tactic: Reconnaissance): The source actively probed the target network from outside to discover open ports and running services before attempting any further attack. This is pre-compromise reconnaissance: the scanner is preparing to find and hit an exposed service.
  • T1498 Network Denial of Service (tactic: Impact): A flood of traffic aimed at the target to exhaust bandwidth or server resources and make a service unavailable.

Immediate actions

  • Block or rate-limit the scanning source at the firewall.
  • Check which ports and services responded, and whether any should not be exposed.
  • Expect a follow-up attack and watch for brute force, exploit, or flood traffic.
  • Confirm service impact (is the site or system actually slow or down?).
  • Contact your ISP/upstream provider to filter or rate-limit the flood.
  • Apply rate limiting or a temporary block on the source at the edge firewall.

Longer-term fixes

  • Close unused ports and disable unneeded services.
  • Segment the network so one exposed host does not reveal everything.
  • Enable port-scan detection on the firewall/IDS (e.g. Suricata, Snort) and alert on scans.
  • Document your external exposure so you know what is reachable from the internet.
  • Put public services behind a CDN or DDoS-protection service.
  • Configure rate limits, SYN-flood protection and connection limits.
  • Prepare a written DoS runbook with the ISP's contact details.

ATT&CK mitigations

  • M1056 Pre-compromise; M1031 Network Intrusion Prevention; M1030 Network Segmentation; M1042 Disable or Remove Feature or Program; M1037 Filter Network Traffic

Caveats

  • Detections come from an ML model on network flow data; confirm with firewall, server and authentication logs before concluding compromise.
  • Source IPs may be NAT or shared addresses; attribution is not implied.
