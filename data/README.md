# Data directory (not tracked)

The raw CICIDS2017 CSVs and the merged `clean.csv` are **not stored in this
repository** — together they are ~3 GB, which exceeds GitHub's 100 MB per-file
limit. Regenerate everything locally with the steps below.

## 1. Download CICIDS2017

The dataset is public, from the Canadian Institute for Cybersecurity (UNB):

- Official page: <https://www.unb.ca/cic/datasets/ids-2017.html>
- Kaggle mirror: <https://www.kaggle.com/datasets/cicdataset/cicids2017>
- Hugging Face mirror: <https://huggingface.co/datasets/c01dsnap/CIC-IDS2017>

## 2. Lay the files out like this

The loader accepts either labelling variant; you do not need both.

```
data/
├── raw/
│   ├── TrafficLabelling/            # "GeneratedLabelledFlows.zip" contents
│   │   ├── Monday-WorkingHours.pcap_ISCX.csv
│   │   ├── Tuesday-WorkingHours.pcap_ISCX.csv
│   │   ├── Wednesday-workingHours.pcap_ISCX.csv
│   │   ├── Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv
│   │   ├── Thursday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv
│   │   ├── Friday-WorkingHours-Morning.pcap_ISCX.csv
│   │   ├── Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv
│   │   └── Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv
│   └── MachineLearningCVE/          # "MachineLearningCSV.zip" contents
│       └── (same eight CSV files)
├── subset/                          # optional, created by step1
└── clean.csv                        # generated by step1
```

## 3. Build the cleaned dataset

```bash
python step1_load_clean.py      # data/raw/**.csv  ->  data/clean.csv
python check_data.py            # sanity check: rows, classes, nulls
```

`data/clean.csv` is ~450 MB (957K flows, 80 features) and stays local.

## 4. Regenerate the rest

```bash
python step2_baseline.py   # XGBoost baseline, 3-fold OOF
python step3_alerts.py     # predictions -> alerts -> incidents + ATT&CK
python step5_hard_eval.py  # chronological / LOAO / cross-capture eval
python step6_demo_page.py  # outputs/demo.html
```

`outputs/predictions.csv` and `outputs/demo.pdf` are ignored for the same size
reasons; everything else under `outputs/` is committed so the README numbers
can be checked without re-running the pipeline.
